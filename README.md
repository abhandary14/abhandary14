### ⭐ Featured work

- **[LedgerWatch](https://github.com/abhandary14/ledger_watch)**: Multi-tenant REST backend that ingests financial transactions, runs pluggable risk analyzers and raises severity-ranked alerts. Alerts move through an OPEN → ACKNOWLEDGED → RESOLVED lifecycle with a write-once audit log, and CI blocks merges on lint and tests against PostgreSQL.<br>
  <sub>Django REST Framework · PostgreSQL · Docker · GitHub Actions · Jenkins</sub>

- **[LLM failure detection](https://github.com/abhandary14/agent-failure-detection)**: Monitoring for a tool-calling LLM chatbot. A deterministic flagging layer inspects each tool-calling trace and decides whether the model's behavior can be trusted. A failure-injection harness then measures per-check precision and recall to prove the layer catches what it claims to.<br>
  <sub>Python · Llama 3.1 8B (local, via Ollama) · tool calling</sub>

- **[RAG evaluation & monitoring](https://github.com/abhandary14/rag-evaluation-monitoring)**: Retrieval-augmented generation pipeline with evaluation and monitoring built in.<br>
  <sub>Python</sub>
